Chalkle API

The endpoints behind the Chalkle app. Everything Chalkle serves to its own pages, documented in JSON form.
No auth required

Quick Start

Chalkle serves a small REST surface from its own server. Every endpoint returns JSON (or streamed media for the relays). Here is the shape of things:

// Fetch the live TV channel list
fetch('/api/live-tv')
  .then(r => r.json())
  .then(channels => console.log(channels));

// Fetch sports categories for Live TV
fetch('/api/livetv/sports')
  .then(r => r.json())
  .then(sports => console.log(sports));

Endpoints

EndpointWhat it returns
GET/api/live-tvThe line-up of 24/7 channels (id, name, logo, category).
GET/api/live-tv/<id>HLS relay for one channel. Playlists and segments are rewritten through Chalkle so the stream plays directly in the app.
GET/api/livetv/sportsAvailable sports categories for the Live TV tab.
GET/api/livetv/matches?sport=…Live matches with streams resolved server-side. Only watchable matches are included, so dead sources never reach the app.
GET/api/livetv/img/<token>Team badge / event poster proxy for match cards.
GET/api/live-tv/adminAdmin channel management.
GET/api/ai/convosSaved AI conversation history.
GET/api/ai/chat?q=…AI chat completion endpoint (also accepts POST with a message body).
GET/_syncCross-device settings sync.
GET/uv/…Ultraviolet proxy routes for opening sites inside the app.
GET/cloud/*, GET/music/*Cloud gaming streams and music relays.
GET/game-builds/<name>/…Self-hosted games served as static files, playable at their real origin.

Example: Live TV channels

fetch('/api/live-tv')
  .then(r => r.json())
  .then(channels => {
    channels.forEach(ch => {
      console.log(ch.id, ch.name, ch.logo);
    });
  });

Example: Live matches

// Grab everything watchable right now for football
fetch('/api/livetv/matches?sport=football')
  .then(r => r.json())
  .then(matches => console.log(matches));

Guidelines

All endpoints return JSON. No authentication required. Errors use standard HTTP status codes. Anything sensitive (tokens, upstream keys) is resolved server-side and never exposed to the page.

Note: the app's Live TV sports data comes from the Streamed API (streamed.pk) under the hood. Chalkle wraps it server-side so the app only ever talks to its own endpoints. If you are building something on top of Chalkle, use the endpoints above, not upstream directly.
